# Физика · Лаборатория ЕГЭ-2027

Автономное учебное приложение с интерактивной веб-версией и Android-контейнером. Обе версии используют одну и ту же HTML/CSS/JavaScript-реализацию, физические модели и локальное хранилище.

## Запуск веб-версии

Откройте PowerShell в корне проекта и запустите локальный сервер:

```powershell
python -m http.server 8000 --directory web
```

Затем откройте `http://localhost:8000`. Для установки сайта как приложения нужен HTTPS или localhost; service worker сохраняет оболочку сайта для работы без сети.

## Android

Откройте папку `android` в Android Studio и соберите приложение через **Build > Build APK(s)**. Перед сборкой задача Gradle `syncSharedWebApp` копирует актуальный сайт из `web/` в Android assets, чтобы мобильная и веб-версии оставались одинаковыми. Для ручного обновления assets:

```powershell
.\scripts\sync-android-assets.ps1
```

Проект рассчитан на Android SDK 34, Android Gradle Plugin 8.5.2 и Java 17.

## Возможности

- 15 тем в четырёх разделах: механика; молекулярная физика и термодинамика; электродинамика; квантовая физика.
- Подробные заметки по всем 15 темам, пошаговые выводы и интерактивные графики. Формулы заданы в LaTeX и отображаются локальным MathML-рендерером без сетевых зависимостей.
- Механика с управляемыми телами, несколькими силами, столкновениями, трением, сопротивлением воздуха, выталкивающей силой и выбором среды (Земля, вода, Луна, невесомость).
- Молекулярный опыт с попарными столкновениями частиц, подвижным поршнем, изотермическим, изобарическим и изохорическим процессами и p–V-графиком.
- Объединённая лаборатория электромагнетизма: электрическое поле точечных зарядов, движение зарядов в магнитном поле под действием силы Лоренца и электромагнитная индукция.
- Интерактивный конструктор цепей: пустое поле, перетаскиваемая палитра с источником, резистором, реостатом, лампой, ключом, конденсатором, катушкой, диодом, амперметром и вольтметром. Обычное нажатие выбирает элемент для настройки; двойной щелчок на компьютере или удержание на телефоне начинает соединение проводом, а нажатие на второй элемент завершает его. Параметры настраиваются ползунком или точным ручным вводом. Узловой расчёт показывает токи и напряжения приборов, яркость лампы зависит от мощности, а переворот диода меняет направление на схеме.
- Симуляции волн, тонкой линзы, атомных уровней и радиоактивного распада.
- Тренажёр с ответами и объяснениями, экзаменационный таймер на 235 минут и карта из 26 заданий.
- Ссылки на внешние банки задач: [Профиматика](https://bank-zadach.ru/build) и [Решу ЕГЭ по физике](https://phys-ege.sdamgia.ru/).
- Офлайн-режим; статистика, параметры последнего опыта, ответы и отметки экзамена хранятся на устройстве.

## Основа содержания

В качестве источников школьных тем и формата экзамена использованы упомянутые пользователем проекты документов ФИПИ «ФИ-11 ЕГЭ 2027 КОДИФ» и «ФИ-11 ЕГЭ 2027 СПЕЦ». Спецификация задаёт 26 заданий: 20 с кратким ответом и 6 с развёрнутым ответом, 235 минут и максимум 45 первичных баллов. Расчётные симуляции служат учебными моделями и упрощают реальные процессы.
